# Paper Source

This folder contains the IEEE-style LaTeX source, figures, tables and references for the pharmaceutical stock-direction research paper.

To compile in Overleaf:
1. Create a blank project.
2. Upload the contents of this folder.
3. Compile `main.tex` using pdfLaTeX.

The repository contains preliminary research outputs. A corporate-action adjustment issue affecting one supplied market-data series remains under source standardisation, so reported metrics are preliminary rather than final verified empirical results.
